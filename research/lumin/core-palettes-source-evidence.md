# Core editing palettes: shipped HTML/CSS reconstruction evidence

This packet traces the already-downloaded Lumin JavaScript under `toolbar-source/markup_files`. It does not execute captured code, use screenshots, inspect native implementation, or make claims about PDF functionality. The parent task owns live DOM/computed-style measurements. Source declarations below should be joined to those measurements before changing UI geometry.

The machine-readable rules are in `core-palettes-source-rules.json`. Verbatim bounded excerpts, original artifact hashes, excerpt hashes, and zero-based character/UTF-8 byte spans are in `toolbar-source/extracted/core-palettes/manifest.json`. End offsets are exclusive. `extract.py` checks every byte span against the downloaded artifact; it never imports JavaScript.

## Shape, Draw, Text tools

All three legacy panels use base palette module7372858: flex column, gap16, padding16; finite width argument sets width100%, min-width300 and a max-width. Shape passes313, Draw304, Text274. The Text min-width300 therefore takes precedence over max-width274. These are declarations, not proof of the final popper width. Shape toolbar metadata also declares contentDOMWidth312, but the shown toolbar call does not pass that metadata into its popper.

Shape module2189580 renders Shape heading,7-column icon grid with8px gaps, Style heading, Fill/Border line tabs, active tab panel, Opacity heading, opacity row. Registry order is Rectangle, Ellipse, Line, Arrow, Polyline, Polygon, Cloud, Star, Cross, Tick; the10 controls form7+3 rows. Icon controls are32px, original glyphs24px. Each selected glyph takes the active tool's `StrokeColor.toHexString()`. The selected button background uses `le_main_primary_container`. Current stored colors must not be replaced with source presets merely because a selected icon differs from a preset swatch.

Tabs render Fill first, Border line second. Both remain present when Fill is unsupported. Initial selected tab is the first supported value in `{FILL:FillColor,STROKE:StrokeColor}`. Rectangle/Ellipse/Polygon/Cloud/Star support Fill and initially select Fill. Line/Arrow/Polyline/Cross/Tick disable Fill and initially select Border line. Fill has a no-fill swatch and colors only. Border line has colors followed by stroke width; it has no no-fill slot. The palette inside either tab has4px left padding. Tabs themselves use pill backgrounds,32px wrapper height and8px lower margin; disabled opacity0.5. The inner TabsList uses `le_main_surface_container`, while its outer wrapper uses `le_main_surface_container_lowest`.

Draw module628246 renders stroke width, StrokeColor swatches, then opacity, with8px gaps and no headings. Text module670272 renders Choose style + Underline/Squiggly/Strikeout buttons on one row, a zero-margin divider, colors, opacity. The tool icons are8px apart. Text highlight reuses module670272 without a tools array, so it has only colors and opacity.

## Colors, sliders, inputs

Legacy palette module82830 uses a flex wrapping row, center alignment, space-between, visible overflow and nonshrinking children. Dots are22px circles with a1px Kiwi outline-variant border (18px in free text). Active color has1px on-surface outline offset2px. An invisible pseudo-element extends3px around the dot. No-fill is first when enabled: transparent fill, same border,1px red `#f2385a` diagonal. The final32px button holds the original24px color-picker SVG.

Seven preset colors are selected by tool family; exact RGBA arrays are in the JSON. User custom colors can replace presets, and the legacy component additionally injects a missing current nontransparent color by dropping the first entry. This explains observed color rows that differ from the shipped seven presets. Custom color scopes are independently TextColor,FillColor,StrokeColor. Active matching compares full RGBA values, not RGB alone.

Stroke row module2798867 is32px high, full width, flex row wrap, gap16; it has the24px `md_stroke` glyph, flexible slider and optional60px input. Defaults are min0.1,max20; MUI's shipped default step is1. On change the legacy component accepts only an in-range value and applies `Math.round`. The suffix `pt` is a separate adornment. Current value comes from current `style.StrokeThickness`; no component default value is declared.

Shared Slider wrapper3245585 sets16px thumb, outline1, no shadow, no thumb after halo. Its track uses legacy on-surface-variant; rail uses outline-variant/opacity1; both have−2px margins and rail widthcalc(100% +4px). The underlying medium horizontal MUI root has4px rail height and13px vertical padding. Marks are2px circles. Eraser overrides the row to min8,max32,step8,marks=true,hideInput=true, retaining the stroke glyph. Its marks are8/16/24/32. Eraser uses palette maxWidth304 inside toolbar containerMaxWidth312 and contains no title or numeric input.

Opacity module6422015 uses0–100, integer-rounded percentage; input suffix `%` is a separate adornment and changes write value/100. It has an optional heading, enabled for Shape. The row has16px gap and60px input. The rail is12px high, absolute top50%, shifted by`translateY(calc(-50% -2px))`, and pill-rounded. The normal MUI rail/track are invisible. Two background layers are rendered in order: opaque white-to-black horizontal gradient, then repeating16×16 PNG checkerboard with1px outline-variant border. Static decoding of the embedded PNG found8px squares alternating black alpha20/255 and transparent; no image was rendered. The thumb changes to legacy surface background plus outline border.

Numeric input module7685342 defaults to32px height,8px radius, transparent background, outline-variant1px border, Inter14px/420/150%. The suffix inherits this14px type. Headings instead use legacy title-small: Inter14px/520/170%. Input hover/focus roles and individual padding are in the rules. Do not use12px numeric/suffix text merely because the nearby descriptions use12px.

## Highlight has two shipped branches

Legacy Highlight has Text highlight (H), then Freehand highlight with description Great for scanned PDFs. Menu padding is8px. Medium rows have8px padding, radius8 and minimum height40; the text is14px/420 and description12px/420 with4px gap. The property suffix holds the original24px more glyph in a32px button. Text styles reuse the text palette without tool buttons; freehand styles reuse Draw. Navigation rows suppress the property buttons, description and `(H)`, and are rendered directly without the normal menu wrapper. Selected text-row state uses currentTool in normal menus and activeToolName in navigation; the freehand row uses currentTool in both.

New Highlight is selected only when `useToolbarVariant()==='v2'` and the control was not mounted as the navigation popover. It declares283px main menu,236px style submenus,10px submenu padding, sideOffset8,alignOffset−4. Rows use Radix Item composition and Phosphor icons, with28px property target and14px dots. Text style submenu has labeled Color and Opacity. Freehand adds labeled Stroke weight. New numeric fields embed suffix into the text string, use32×60px fields/padding-x10/radius8, and parseFloat/clamp. New Stroke weight starts at0 through20/step1; Opacity0–100/step1.

New palette module194019 uses16px dots and2px active rings/2px offsets. Spread mode has2px horizontal padding and20px picker wrapper. It does not inject a missing current color as legacy module82830 does. New semantic Tailwind variables (`border`, `ring`, `popover`, `foreground`) must be resolved against the active stylesheet/live state. They are not interchangeable with legacy `le_main_*` or Kiwi palette roles.

## Added slider token provenance

Shipped module9695937 in `2wlhxxp1u3z2q.js` exports `themes.light` and `themes.dark`.
